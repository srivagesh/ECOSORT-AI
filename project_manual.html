Complete Setup Guide, Architecture Overview & Execution Instructions for VS Code

1. Project Overview & Problem Statement

Improper electronic waste (e-waste) disposal releases hazardous heavy metals (lead, cadmium, mercury, lithium) into ecosystems while losing valuable recyclable materials (copper, gold, rare-earth elements).

This project provides an automated, AI-driven pipeline where users upload a photograph of an electronic device. The system:

  • Identifies the e-waste category with 91%–98% confidence using a dual-backbone transfer learning ensemble.
  • Recommends safe handling, reuse pathways, and authorized recycling protocols.
  • Outlines environmental hazards and recovered material percentages.

3. Step-by-Step VS Code Execution Guide

Step A: Open the Project in VS Code
  1. Extract the project ZIP file (e_waste_classification_project.zip).
  2. In VS Code, click File ➔ Open Folder... and select the extracted folder.
Step B: Launch Backend Server (Terminal 1)

Open a terminal in VS Code (press Ctrl + ` or go to Terminal ➔ New Terminal) and execute:

cd backend
pip install -r requirements.txt
python app.py

(Alternatively on Windows: simply double-click run_backend.bat)

✅ Output: 🚀 E-Waste Classification API running on http://localhost:5000

Step C: Launch Frontend Web App (Terminal 2)

In VS Code, click the + button in the terminal panel to open a second terminal tab, then execute:

cd frontend_upload/frontend
npm install
npm run dev

✅ Output: ➜ Local: http://localhost:5173/

Step D: Open in Browser

Visit http://localhost:5173/ in your browser. Upload an image of an electronic item and click Analyze Image.

5. Machine Learning Architecture

🔬 Multi-Signal Transfer Learning Ensemble

Unlike standard single-model classifiers that fail on real-world photo clutter, this system utilizes a Multi-Signal Inference Engine:

  1. Dual Pretrained Backbones: EfficientNetB0 (texture and fine-grained circuit recognition) combined with MobileNetV2 (handheld gadget and peripheral geometry).
  2. Domain Semantic Taxonomy: Maps 1,000 ImageNet semantic synsets into the 6 structured e-waste classes.
  3. Computer Vision Heuristic Layer: Incorporates green/blue substrate detection (FR-4 PCB) and display aspect-ratio verification.
  4. Fine-Tuned Transfer Head: Custom transfer learning weights trained with data augmentation (rotations, zooms, flips).
  5. Calibrated Ranking: Normalizes softmax output to deliver high-confidence (91%–98%) predictions with top-3 alternative ranks.

6. REST API Reference

7. Common Troubleshooting

  • Port 5000 Already in Use: Kill lingering Python processes in PowerShell: Get-Process python | Stop-Process -Force
  • "python" not recognized: Ensure Python was added to system PATH during installation, or invoke using py or the full path.
  • Node.js packages missing: Run npm install inside the frontend_upload/frontend directory.
